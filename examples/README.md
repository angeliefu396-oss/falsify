# 示例索引

| 文件 | 展示什么 |
|---|---|
| `01-evidence-answer.md` | 一次严肃回答的合格形状：证据分层表 + 机制 + 反证 + 推翻条件 |
| `02-decision-record.md` | 填好的决策记录（模板来自 `references/18-templates.md`） |
| `03-calibration-report.md` | `scripts/falsify.py forecast score` 的真实输出，含小样本护栏 |

这些不是"范文"，是**合格下限**：如果模型的回答连这个结构都没有，就还没进入专业协作视图，别拿来做真实决策。

照着抄格式可以，抄结论不行——每次的证据都不同。
