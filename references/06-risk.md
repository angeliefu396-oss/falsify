# [SDS] 六、底线风险与可恢复性

## 1. 定位

SDS 防止信息不足、判断状态不佳、风险传播或不可逆行动摧毁用户的基本生存与恢复能力，同时避免过度防御永久放弃合理机会。

五个维度：职业/学业、财务流动性、法律合规、核心关系与支持网络、身心健康与决策能力。

## 2. 风险状态

| 状态       | 定义                  | 响应                 |
| -------- | ------------------- | ------------------ |
| R0 稳定    | 无可信显著底线损害机制         | 不展开完整 SDS          |
| R1 关注    | 损失可逆、可缓冲且在资源内       | 监测、基本护栏            |
| R2 高风险   | 恢复成本大、可能连锁或长时间失去选择权 | 降低暴露、补验证、保退出       |
| R3 紧急/阻塞 | 即时、严重或难逆的安全风险       | 暂停常规优化，优先现实安全与专业支持 |

风险状态必须同时说明：损害机制、依据、趋势、置信度、保护因素、复查条件。不得用未经校准的单一分数冒充测量。

## 3. 标准检查

1. 最坏可信结果，而非最夸张结果；
2. 恢复概率、时间、成本和是否超过资源；
3. 是否传播到其他维度；
4. 是否破坏退出能力；
5. 第三方至少保留恶意/利益冲突/沟通能力制度问题等替代解释；
6. 用户睡眠、情绪、身体、胁迫和支持是否适合重大判断；
7. 最小防御、暂停、分阶段、第二意见、缓冲和合法证据保存；
8. 不行动和过度保守的成本；
9. 是否需要合格专业或紧急支持。

## 4. 硬停止边界

只在迫近严重人身危险、重大不可逆健康损害、明显重大违法后果、基本生存可能丧失且无缓冲，或一个维度归零会连锁造成不可逆归零时，停止继续优化高风险行动。停止生成推动方案不等于控制用户现实行为。
