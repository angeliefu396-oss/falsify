# [DECISION] 八、循证决策工作流

## 1. 使命

在多个现实选项、不确定证据、用户能力、风险和真实偏好之间形成可审查的方向。决策工作流负责“选什么”，不负责把未确认方向伪装成执行计划。

## 2. 决策状态

- D0 问题未定义；
- D1 选项未成形；
- D2 证据评估中；
- D3 暂定方向；
- D4 可执行决定；
- D5 因新证据重新开放。

## 3. 十阶段流程

### D1 定义决策

明确决策句、截止时间、是否必须现在决定、用户是否真实拥有选择权、不可接受结果和可逆性。列出 A/B/C、维持现状、延迟、混合方案、可逆试验和退出方案；不强行二选一。

### D2 偏见、利益和偏好

记录用户当前倾向、原因、外部压力、利益相关者、希望得到的结论、最害怕的结果、愿意和不愿承受的代价。自我报告和过去行为明显不一致时，只能标为“偏好尚未经过现实验证”。

### D3 证据计划

对每个会改变排序的问题记录当前证据、缺失信息、获取方式、预计质量、成本和改变决定的可能性。

### D4 信息价值

优先获得最可能改变选择、成本合理且能解除阻塞未知的信息。不要平均研究所有问题。

### D5 检索与证据审计

获取支持、反向和独立证据；说明已检索、未检索、时效和适用范围。需要时调用横纵研究。

### D6 选项比较

每个选项分析：预期收益、主要代价、成功条件、关键假设、证据强度、可逆性、最坏可信结果、机会成本、SDS 影响、能力匹配、偏好匹配和现实试验。

```markdown
| 选项 | 收益 | 代价 | 成功前提 | 证据与未知 | 可逆性/退出 | 风险 | 能力匹配 | 偏好匹配 |
|---|---|---|---|---|---|---|---|---|
```

未经用户确认的权重不能被机械总分替代。可以用阈值、排序或敏感性分析，但必须说明规则。

### D7 敏感性与反事实

检查哪个事实、概率、权重或底线变化会改变排序；指出未选择选项的结果通常是不可观察反事实，不能事后伪装成已证实。

### D8 形成推荐

使用信息呈现、弱建议、条件建议或较强建议。说明证据强度、最薄弱环节和当前不建议选择的理由。

### D9 执行权限

将建议与权限分开：仅研究、信息获取、可逆试验、分阶段执行、完整执行。涉及外部或不可逆行动时逐次确认。


### D10 可证伪与用户确认

建立成功指标、失败指标、首次检查时间、推翻条件、不作为基线和用户需要确认的权衡。重大决定进入 D4 前，用户应理解主要证据、未知、代价和风险。

## 4. 决策合同

达到 D4 时可生成：

```markdown
# 决策记录
- 决策编号：
- 决策日期：
- 问题与期限：
- 候选选项：
- 最终选择：
- 未选择方案：
- 用户目标与不可接受结果：
- 推荐强度：
- 执行权限：
- 核心事实与证据强度：
- 用户偏好：
- 关键假设与阻塞未知：
- 可逆性、风险边界与退出：
- 成功/失败指标：
- 推翻条件：
- 不作为基线：
- 首次复盘：
- 是否建立预测记录：是/否
```

## 5. 停止与交接

达到当前可逆性所需证据、阻塞未知已解决、新证据不再改变推荐、继续检索价值低于成本或可逆试验信息价值更高时停止研究。方向确认后交给执行工作流；关键可兑现假设可交给预测校准。
