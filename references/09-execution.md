# [EXECUTION] 九、路径与杠杆优化

## 1. 进入门

开始前检查：目标是否明确、战略是否确认、用户是否同意、阻塞未知是否解决、风险边界和执行权限是否清楚、资源是否仍有效。条件不满足时返回决策或 SDS。

## 2. 目标合同

> 在【截止时间】前，使【对象】从【当前基线】达到【可观察结果】，同时不突破【资源与风险护栏】。

区分结果目标、阶段成果、领先指标、活动指标、护栏指标和诊断指标。

## 3. 十二阶段流程

1. **前提与假设**：列关键假设、证据、验证、期限和失效后果；阻塞假设未解决不排完整计划。
2. **第一性拆解**：结果、必要条件、当前状态、差距、完成标准和可控性。
3. **资源盘点**：真实可用时间、精力、资金、技能、工具、人脉、权限和专业支持。
4. **容量预算**：保留突发、恢复和估计误差；任何比例只是待验证设计参数，不是普遍规律。
5. **依赖图**：前置、外部等待、可并行项、关键路径和失败影响。
6. **杠杆识别**：结果影响、成本、信息增益、可逆性、依赖和复用价值。
7. **资源分配**：资源优先给当前瓶颈；说明偏离默认策略的原因和复查点。
8. **最小可行攻击/试验**：可在合理短周期启动，有成本上限，产生现实反馈并验证关键假设。
9. **摩擦设计**：降低启动动作，预置环境，减少切换，明确负责人，处理他人配合、完美主义和恢复。
10. **指标合同**：结果、领先、活动、护栏、数据来源、频率、预警、红灯、通过标准和防作弊。
11. **检查点与回退**：目标是否仍有效、外部条件、指标、失败归因、补救和回退工作流。
12. **近期启动清单**：同时承诺的近期行动最多三项；分析依据和长期备选不受此数量限制。

## 4. 失败归因

区分目标无效、战略错误、计划错误、资源错误、假设错误、环境摩擦、实际未执行、指标错误和正常随机波动。不得默认归因于“不够努力”。
