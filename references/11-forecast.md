# [FORECAST] 十一、决策与预测校准工作流

## 1. 目的与边界

预测校准的目的不是把所有想法强行数字化，也不是证明用户“客观”。它用于：

- 把会影响决定的未来判断改写成可兑现命题；
- 在结果发生前保存当时的依据、概率和未知；
- 新证据出现时记录更新，而不是事后重写记忆；
- 兑现后区分预测误差、执行偏差、定义问题和随机性；
- 用一批可比预测观察校准和区分能力的变化。

预测评分不能替代价值判断、风险管理或决策效用。不可兑现的价值命题、未选择方案的反事实和无法定义结果的故事，不应伪装成可评分预测。

## 2. 四层结构

### F0 决策记录

保存为什么要做这个选择、有哪些选项、证据和偏好是什么。它评价决策过程，不直接用 Brier 计分。

### F1 原子预测

把决策依赖的关键未来主张拆成一个或多个具有明确截止日期和兑现标准的命题。预测必须在结果未知时登记。

### F2 更新日志

新证据出现时保留旧概率、新概率、证据和变化理由。不得覆盖初始值。

### F3 兑现与复盘

按预先规则确定发生、未发生、作废或无法判定；对有效预测评分，并把过程质量与结果分开。

## 3. 建立预测的进入门

只有同时满足以下条件才建立可计分预测：

1. 命题描述的是未来或尚未揭晓的离散结果；
2. 有明确时间窗；
3. 有不依赖事后心情的兑现标准；
4. 有指定或可确定的兑现来源；
5. 登记时结果未知；
6. 用户确认这是自己的最终概率，而非 AI 擅自替用户登记。

不满足时先澄清、拆分、改为阈值预测、保留为不可评分假设，或明确放弃计分。

## 4. 预测卡

```markdown
# 预测卡
- 预测编号：
- 关联决策/案例：
- 创建时间与时区：
- 命题：在【截止时间】前，【可观察事件】是否发生？
- 结果空间：发生/未发生（或互斥且穷尽的多类别）
- 兑现标准：
- 兑现来源与优先级：
- 模糊/延期/取消时的处理规则：
- 初始概率：
- 概率所有者：用户/外部预测者/模型建议后经用户确认
- 参考类别与基础率：
- 支持证据：
- 反向证据：
- 关键假设：
- 证据强度：
- 用户控制程度：低/中/高
- 预定更新触发：新证据/固定日期/关键事件
- 锁定或最后更新截止：
- 可评分状态：是/否，原因
```

## 5. 概率形成协议

1. **先定义再估计**：不能用概率掩盖命题含糊。
2. **先外部视角**：能找到参考类别时，先记录基础率和可比性限制。
3. **分解**：复杂命题拆成真正影响总体概率的条件，不机械相乘未经验证的数字。
4. **内部视角**：再加入本案例的具体证据。
5. **反证**：写出最可能使判断过高和过低的证据。
6. **范围与极端值纪律**：没有极强、可复核证据时谨慎使用 0%/100%；谨慎不等于永远报 50%。
7. **所有权确认**：AI 可以提出起始范围和依据，但最终登记概率必须由用户确认；分别保存 AI 建议和用户概率，不能混成一条。

## 6. 更新日志

```markdown
| 时间 | 旧概率 | 新概率 | 新信息及来源 | 信息类型/核验 | 更新方向与幅度理由 | 是否改变决策 |
|---|---:|---:|---|---|---|---|
```

- 有意义的新证据到来时更新；不为了“频繁”而无信息抖动。
- 小步更新是常见纪律，不是硬规则；决定性证据可以大幅改变概率，但必须说明。
- 禁止删除旧概率、只保留最准的一次、在得知结果后回填时间或理由。

## 7. 兑现协议

兑现前先按预定标准确定：

- **发生（1）**；
- **未发生（0）**；
- **作废**：事件取消、定义前提未满足，且预先规则允许；
- **无法判定**：来源冲突或标准不充分；不得强行计分。

若规则本身有缺陷，应登记“兑现定义错误”，不能为了获得好分修改结果。作废率和无法判定率也要报告，防止用模糊命题逃避评分。

## 8. Brier 评分及正确解释

二元预测：

[  
BS=(p-o)^2  
]

其中 (p) 为 0 到 1 的预测概率，(o) 为结果（发生=1，未发生=0）。越低越好。

例：预测 70%，发生时为 0.09，未发生时为 0.49。

必须同时遵守：

- 0.25 只等于“所有二元问题都报 50%”的分数，不是任何问题集上的通用随机基线；
- 比较能力时，应在同一批问题上对照基础率预测、简单参考模型、先前版本或另一预测者；
- 不同难度、基础率和选题的问题不能只看平均 Brier 就直接比较；
- 多类别预测需要各类别概率总和为 1，并使用适当的多类别评分；
- 连续数值不要直接套二元 Brier，可改成预先定义的阈值命题，或使用合适的区间/分位数评分；
- 评分规则衡量概率预测，不单独证明因果解释、价值选择或执行方案正确。

## 9. 初始、最终和全过程评分

为防止挑选最有利版本，预先选择评分方式：

- **初始分**：评价最初判断；
- **最终分**：评价锁定截止前最后一个有效概率；
- **全过程分**：按预定频率或时间权重评价更新过程。

个人轻量使用默认同时保留初始分和最终分；若没有可靠自动记录，不声称计算精确全过程分。不能事后选择三者中最好看的一个作为主指标。

## 10. 校准、区分度与样本量

### 校准

若一批 70% 预测中约 70% 发生，则该档在该样本上校准较好。

### 区分度/分辨率

好的预测者不仅平均不偏，还应把更可能发生的事件赋予更高概率。始终报基础率可能校准尚可，却没有足够区分度。

### 样本量纪律

- 每个概率档必须显示预测数 N；
- N 很小时只描述，不下“你过度自信/已经校准”的稳定结论；
- 相邻档样本过少时可以预先定义合并规则，不能看完结果再挑分箱；
- 版本改动应基于重复模式、足够样本或高影响结构性错误，不因一两次输赢修改全局规则；
- 若能计算，报告命中率的不确定区间；不能计算时明确“小样本，方向仅供观察”。

本系统不把某个固定 N 宣称为普遍统计充分。可在项目合同中设置保守发布门，但须标明这是运营规则而非自然定律。

## 11. 预测选择偏差

必须记录：登记数量、兑现数量、作废、无法判定、逾期未处理和领域分布。用户若只预测容易或感兴趣的问题，分数不代表一般判断能力。

同一命题的多个更新不能被当成多个独立案例。个人可控结果必须标记控制程度；其误差同时反映判断与执行，不能与纯外生事件直接等同比较。

## 12. 决策过程与结果分离

兑现后使用：

| 过程质量 | 现实结果 | 解释               |
| ---- | ---- | ---------------- |
| 高    | 好    | 正常成功，但仍检查是否可复制   |
| 高    | 坏    | 风险实现或随机性，不自动推翻过程 |
| 低    | 好    | 可能侥幸成功，不能奖励坏流程   |
| 低    | 坏    | 需要修正决策、证据或执行流程   |

过程质量至少检查：当时可得信息、证据分层、反证、偏好、可逆性、风险、概率、更新和执行是否符合预先标准。不能用结果倒推“当时早就应该知道”。

## 13. 预测复盘

```markdown
# 预测兑现与复盘
- 预测编号：
- 结果与来源：
- 兑现状态：发生/未发生/作废/无法判定
- 初始/最终/全过程分：
- 对照基线及其分数：
- 当时过程质量：高/中/低，依据
- 主要误差来源：定义/基础率/证据/假设/更新/执行/随机性/兑现规则
- 哪条反向证据被忽略：
- 哪次更新合理或不合理：
- 是否改变原决定：
- 最小流程修正：
- 不应修改的部分：
```

## 14. 汇总报告

当有效样本允许时报告：总预测数、兑现/作废/无法判定、平均初始和最终 Brier、同题集基线、按预先定义档位的 N/预测均值/实际频率/差距、区分度观察、领域分布、更新次数、最常见错误和下一阶段训练目标。

“平均 Brier 下降”不能作为唯一成功标准；至少同时检查对照基线、校准、区分度、覆盖/作废、是否选择性登记以及决策是否得到更好反馈。
