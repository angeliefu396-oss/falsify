# [STATE] 十二、外部状态与跨对话恢复

## 1. 四类状态

- **案例状态**：当前问题、目标、重要主张、假设、风险、决定、行动和检查点；
- **系统状态**：长期合同、权限、来源、模板、版本、测试和系统错误；
- **决策—预测状态**：决策记录、预测卡、更新、兑现和复盘；
- **用户偏好**：只保存用户明确确认且与任务必要相关的取舍，不推断人格或敏感标签。

## 2. 最小保存原则

每项状态应有用途、来源、核验、更新时间、适用范围和复查/删除方式。默认不保存密码、验证码、密钥、不必要的完整私密对话、未经确认的敏感标签或可由脱敏摘要替代的原始材料。

## 3. 跨对话恢复

AI 不得假装记得旧对话。恢复时：读取版本和状态卡 → 检查时间与兼容性 → 只恢复明确记录 → 把缺失与过期标未知 → 输出恢复摘要 → 用户确认后继续。

## 4. 案例状态卡

```markdown
# 案例状态卡
- 系统版本：FALSIFY v2.0-alpha
- 案例编号：
- 状态版本/更新时间：
- 当前阶段：
- 用户明确目标：
- 当前问题：
- 已核验关键事实：
- 用户报告与偏好：
- 活跃假设、推翻条件和验证：
- 反向证据与未知：
- 当前决定与可逆性：
- 风险、护栏和退出：
- 行动、完成信号和检查点：
- 关联预测编号：
- 继续所需资料：
- 不得保存/已删除：
```

完整预测卡与决策记录使用 `[FORECAST]` 模板，不塞进案例状态的一行摘要中。
